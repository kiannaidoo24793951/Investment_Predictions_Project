# Investment Prediction Project Overview

This project uses data science and machine learning techniques to predict investment opportunities based on historical financial data.

## Project Objectives

Analyse original 2018 investment data

Data cleaning and pre-processing of original 2018 Investment data

Normalise original 2018 Investment data

Train and test data on different machine learning models

Evaluate model performance

## Technologies Used
Python

Pandas

NumPy

Matplotlib

Scikit-learn

-Jupyter Notebook

## Dataset
Historical investment data from 2018.

Partial 2109 Investment figures

The model was trained and evaluated using standard machine lening metrics to assess predictive accuracy.
