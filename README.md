Investment Prediction Project Overview

This project uses data science and machine learning techniques to predict investment opportunities based on historical financial data.

Project Objectives

Analyse investment data
Identify predictors of investment perfmance
Build predictive models -evaluate model performance

Technologies Used
Python
Pandas
NumPy
Matplotlib
Scikit-learn
-Jupyter Notebook

Dataset
Historical investment data from 2018.

The model was trained and evaluated using standard machine lening metrics to assess predictive accuracy.
